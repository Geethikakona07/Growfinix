# 03 — Preference Collection Strategy

## Startup Investment Firm — Zero-Party Data Collection

---

## Data Collection Framework

### What We Collect

| Data Category | Specific Data Points | Collection Method |
|---------------|---------------------|-------------------|
| **Demographics** | Name, email | Signup form |
| **Risk Profile** | Risk tolerance, comfort level | Quiz Q1 |
| **Goals** | Investment objectives, timeline | Quiz Q2, Q4 |
| **Experience** | Knowledge level, history | Quiz Q3 |
| **Resources** | Amount to invest | Quiz Q5 |
| **Interests** | Preferred sectors | Quiz Q6 |
| **Preferences** | Learning style, communication | Quiz Q7, Q8 |
| **Concerns** | Pain points, objections | Quiz Q9 |
| **Attribution** | Source channel | Quiz Q10 |

### How We Use It

| Data Point | Personalization Use |
|------------|-------------------|
| Risk Tolerance | Show appropriate investments |
| Investment Goal | Tailor content to goals |
| Experience Level | Adjust content complexity |
| Timeline | Recommend appropriate strategies |
| Amount | Qualify and segment leads |
| Sectors | Personalize opportunity emails |
| Learning Style | Choose content format |
| Communication Freq | Set email frequency |
| Concerns | Address objections in nurture |

---

## Value Exchange Matrix

| User Gives | User Gets |
|------------|-----------|
| Contact info | Free investment playbook |
| Quiz responses | Personalized recommendations |
| Engagement data | Relevant content |
| Preferences | Customized experience |
| Feedback | Better service |

---

## Privacy & Compliance

| Requirement | Implementation |
|-------------|---------------|
| Consent | Clear opt-in on signup |
| Privacy Policy | Link on all forms |
| Data Usage | Transparent in privacy policy |
| Unsubscribe | One-click unsubscribe in all emails |
| Data Access | Users can request their data |
| Data Deletion | Users can request deletion |

---

## Data Quality Rules

| Rule | Implementation |
|------|---------------|
| Validation | Email validation on form |
| Deduplication | Check for existing contacts |
| Freshness | Re-qualify leads quarterly |
| Accuracy | Allow preference updates |
| Completeness | Encourage full quiz completion |

---

## Preference Update Strategy

| Trigger | Action |
|---------|--------|
| Quiz completion | Set initial preferences |
| Email engagement | Update interest scores |
| Click behavior | Refine content preferences |
| Consultation | Update profile manually |
| Annual survey | Refresh preferences |
