## Executive Summary

This project delivers a comprehensive **"Value-Exchange" Email Funnel** for a **Startup Investment Firm**, designed to collect zero-party data through interactive quizzes and preference collection. With the phase-out of third-party cookies, this funnel establishes first-party data collection as the foundation for personalized marketing.

## Email Funnel Overview

```
Lead Magnet (Quiz) → Landing Page → Welcome Email → Follow-up 1 → Follow-up 2 → Follow-up 3 → Newsletter
```

| Stage | Goal | Data Collected |
|-------|------|---------------|
| Lead Magnet | Attract signups | Email, name |
| Quiz | Collect preferences | Risk tolerance, goals, experience |
| Welcome | Build trust | Engagement data |
| Follow-ups | Nurture leads | Click behavior, interests |
| Newsletter | Retain & convert | Ongoing engagement |
