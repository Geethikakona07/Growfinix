# 06 — Newsletter Template

## Startup Investment Firm — Weekly Newsletter

---

## Newsletter Structure

```
Subject: [Week] Market Update: [Key Headline]

Header: Firm Logo + Date

Section 1: Market Snapshot (Key indices performance)
Section 2: This Week's Insight (Educational content)
Section 3: Portfolio Tip (Actionable advice)
Section 4: Opportunity Spotlight (Featured investment)
Section 5: Quick Links (Resources)

Footer: Contact, Social, Unsubscribe
```

## Newsletter Best Practices

| Element | Recommendation |
|---------|---------------|
| Frequency | Weekly (Tuesday or Wednesday) |
| Length | 500-800 words |
| Subject Line | Clear, value-driven |
| Preview Text | Complement subject |
| CTA | 1 primary CTA per newsletter |
| Mobile | Fully responsive |
