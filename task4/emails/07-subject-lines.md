## Subject Line Best Practices

| Rule | Detail |
|------|--------|
| Length | 30-50 characters optimal |
| Personalization | Use [First Name] when available |
| Emoji | 1-2 max, relevant to content |
| Urgency | Use sparingly, only when genuine |
| Numbers | Include specific numbers |
| Curiosity | Create intrigue without clickbait |
