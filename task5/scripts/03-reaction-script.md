# Script 3: The Reaction — "I Can't Believe This Game"

**Platform:** YouTube Shorts / Instagram Reels  
**Duration:** 15-25 seconds  
**Hook Type:** Social Proof / Reaction  
**Goal:** Build trust, show genuine excitement  

---

## Script Breakdown

| Timestamp | Visual | Audio/Text | Duration |
|-----------|--------|------------|----------|
| 0:00-0:03 | Face-cam: shocked expression | "Wait... WHAT?!" | 3s |
| 0:03-0:08 | Screen recording: epic moment | "Look at this!" (genuine) | 5s |
| 0:08-0:15 | Gameplay highlight reel | Excited commentary | 7s |

---

## Production Notes

### Visual Style
- Face-cam in corner (picture-in-picture)
- Screen recording as main content
- Zoom effects on key moments
- Reaction emojis as overlays

### Audio
- Genuine voice reaction (not scripted)
- Game audio at 50% volume
- Music: subtle, builds tension

### Caption Text (On-Screen)
```
Frame 1: "😱 NO WAY"
Frame 2: "[Game Feature]"
Frame 3: "FREE DOWNLOAD"
Frame 4: "LINK IN BIO"
```

## Authenticity Checklist

- [ ] Genuine first reaction (don't re-record)
- [ ] Natural speech patterns (no over-acting)
- [ ] Include real gameplay (not staged)
- [ ] Show both wins AND losses
- [ ] Credit the game fairly
