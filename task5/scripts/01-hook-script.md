# Script 1: The Hook — "Wait For It..."

**Platform:** YouTube Shorts / Instagram Reels  
**Duration:** 15-20 seconds  
**Hook Type:** Curiosity Gap  
**Goal:** Stop the scroll, create anticipation  

---

## Script Breakdown

| Timestamp | Visual | Audio/Text | Duration |
|-----------|--------|------------|----------|
| 0:00-0:02 | Black screen → Glitch effect | "You won't believe what happens next..." | 2s |
| 0:02-0:05 | Quick gameplay montage (3 cuts) | Trending audio beat drop | 3s |
| 0:05-0:08 | Character reveal (slow-mo) | "This changes everything..." | 3s |
| 0:08-0:12 | Epic gameplay moment | Music intensifies | 4s |
| 0:12-0:15 | Logo reveal + CTA | "Download FREE — Link in bio" | 3s |

---

## Production Notes

### Visual Style
- Fast cuts (0.5-1 second each)
- High contrast, saturated colors
- Glitch transitions between scenes
- Text overlays with bold, outlined fonts

### Audio
- Trending sound (check Reels/TikTok trending audio)
- Sound effects: whoosh, impact, glitch
- Music: 120-140 BPM electronic/hype

### Caption Text (On-Screen)
```
Frame 1: "WAIT FOR IT..."
Frame 2: "[Game Name] 🔥"
Frame 3: "FREE DOWNLOAD"
```
