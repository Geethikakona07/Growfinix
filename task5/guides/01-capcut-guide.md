# CapCut Editing Guide for Short-Form Video

## Overview

CapCut is a free, AI-powered video editing tool perfect for creating YouTube Shorts and Instagram Reels. This guide covers the complete workflow for producing gaming content.

---

## Setup & Configuration

### Account Setup

| Step | Action | Notes |
|------|--------|-------|
| 1 | Download CapCut Desktop/Mobile | Free version sufficient |
| 2 | Create account | Sync with TikTok for templates |
| 3 | Enable auto-captions | Settings → Captions → Auto-generate |
| 4 | Set default export | 1080x1920, 30fps, High quality |

### Project Settings

| Setting | Value | Reason |
|---------|-------|--------|
| Resolution | 1080x1920 | 9:16 vertical format |
| Frame Rate | 30fps | Smooth gameplay |
| Aspect Ratio | 9:16 | Mobile-first |
| Duration | 15-60s | Optimal for Shorts/Reels |

## Workflow: Gaming Content

### Step 1: Import & Organize

```
1. Create new project
2. Import gameplay footage
3. Create folders:
   - Raw Footage
   - Audio
   - Graphics
   - Exports
4. Rename clips for easy identification
```

### Step 2: Rough Cut

| Action | Shortcut (Desktop) | Purpose |
|--------|-------------------|---------|
| Split clip | Ctrl+B | Cut unwanted sections |
| Delete | Delete key | Remove segments |
| Ripple Delete | Ctrl+Delete | Close gaps |
| Snap to playhead | S | Precision cuts |

### Step 3: AI Auto-Captions

```
1. Click "Text" → "Auto Captions"
2. Select language
3. Choose style template
4. Generate captions
5. Review and correct errors
6. Adjust timing if needed
```

### Step 4: Add Effects & Transitions

| Effect | Use Case | Settings |
|--------|----------|----------|
| Glitch | Scene changes | Intensity: 40-60% |
| Zoom In | Highlight moments | Speed: Fast |
| Shake | Impact moments | Duration: 0.3s |
| Flash | Beat drops | Color: White |
| Blur | Transitions | Duration: 0.2s |

### Step 5: Audio Enhancement

```
1. Add trending music (CapCut library)
2. Layer game audio at 30-50% volume
3. Add sound effects:
   - Whoosh for transitions
   - Impact for highlights
   - Ding for reveals
4. Balance levels (music: -12dB, SFX: -6dB, Voice: 0dB)
```

### Step 6: Export Settings

| Platform | Resolution | Format | Quality |
|----------|------------|--------|---------|
| YouTube Shorts | 1080x1920 | MP4 | High |
| Instagram Reels | 1080x1920 | MP4 | High |
| TikTok | 1080x1920 | MP4 | High |

## Templates & Presets

### Gaming Content Template

```
- Hook: 0-2 seconds (zoom + text)
- Body: 2-15 seconds (gameplay)
- CTA: 15-20 seconds (logo + text)
```

### Caption Style Guide

| Element | Font | Size | Color | Position |
|---------|------|------|-------|----------|
| Main text | Bold sans-serif | 48px | White | Center |
| Outlines | Same | +2px | Black | Behind text |
| Highlights | Bold | 56px | Yellow/Green | Center-bottom |
| CTA | Bold | 40px | White | Bottom third |

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Captions out of sync | Manually adjust timing points |
| Audio not syncing | Check sample rate (48kHz) |
| Export blurry | Ensure 1080x1920 output |
| Effects lagging | Render preview first |
| File too large | Compress in export settings |
