# Pictory AI Video Workflow Guide

## Overview

Pictory is an AI-powered video editing tool that transforms long-form content (podcasts, streams, webinars) into engaging short-form clips. This guide covers the complete workflow for gaming content repurposing.

---

| Plan | Price | Features | Recommended For |

| Starter | $19/mo | 30 videos/mo | Small projects |

### Initial Configuration

```
1. Create account at pictory.ai
2. Connect cloud storage (Google Drive/Dropbox)
3. Set brand kit:
   - Logo
   - Brand colors
   - Font preferences
4. Enable auto-captioning
5. Set default export: 1080x1920
```

## Workflow: Podcast to Shorts

### Step 1: Upload Source Content

| Source Type | Max Length | Best Length | Format |
|-------------|------------|-------------|--------|
| Podcast episode | 3 hours | 30-60 min | MP4, MP3 |
| Live stream | 8 hours | 1-2 hours | MP4 |
| Webinar | 4 hours | 30-60 min | MP4 |
| Interview | 2 hours | 20-45 min | MP4, MP3 |

### Step 2: AI Analysis

```
Pictory AI automatically:
1. Transcribes audio
2. Identifies key moments
3. Suggests highlight clips
4. Detects speaker changes
5. Marks high-engagement points
```

### Step 3: Select Highlights

| Criteria | AI Score | Manual Check |
|----------|----------|--------------|
| Emotional peaks | >80% | ✓ Verify excitement |
| Clear audio | >90% | ✓ Check quality |
| Visual interest | >70% | ✓ Confirm gameplay |
| Duration | 15-60s | ✓ Trim if needed |
| Standalone value | N/A | ✓ Makes sense alone |

### Step 4: Edit & Enhance

```
1. Trim selected clips to optimal length
2. Add auto-captions (AI-generated)
3. Apply brand kit:
   - Logo overlay (corner)
   - Brand colors for captions
   - Intro/outro bumper (optional)
4. Add background music (Pictory library)
5. Adjust audio levels
```

### Step 5: Caption Styling

| Element | Style | Settings |
|---------|-------|----------|
| Font | Bold sans-serif | 48px minimum |
| Color | White with black outline | High contrast |
| Position | Bottom third | Centered |
| Animation | Pop-in | 0.2s duration |
| Background | Semi-transparent | Black, 30% opacity |

### Step 6: Export & Distribution

| Platform | Aspect Ratio | Duration | Export Settings |
|----------|--------------|----------|-----------------|
| YouTube Shorts | 9:16 | <60s | 1080x1920, 30fps |
| Instagram Reels | 9:16 | <90s | 1080x1920, 30fps |
| TikTok | 9:16 | <3min | 1080x1920, 30fps |
| Twitter/X | 16:9 or 1:1 | <2:20 | 1280x720 |

## AI Features Deep Dive

| Engagement | AI engagement score | >75% |

|--------|-------------|----------|
| Standard | Basic transcription | General content |

```
Brand Kit Elements:
├── Logo
│   ├── File: PNG with transparency
│   ├── Size: 200x200px
│   └── Position: Top-right corner
├── Colors
│   ├── Primary: #FF0000 (gaming red)
│   ├── Secondary: #000000 (black)
│   └── Accent: #FFD700 (gold)
├── Fonts
│   ├── Headlines: Montserrat Bold
│   └── Captions: Open Sans Regular
└── Bumpers
    ├── Intro: 2-second logo reveal
    └── Outro: 3-second CTA screen
```

## Batch Processing Workflow

### Step 1: Upload Multiple Sources

```
1. Create project folder
2. Upload 3-5 podcast episodes
3. Set consistent brand kit
4. Apply same caption style
5. Queue for AI analysis
```

### Step 2: Review AI Suggestions

| Episode | Clips Suggested | Selected | Exported |
|---------|-----------------|----------|----------|
| Episode 1 | 12 | 8 | 8 |
| Episode 2 | 10 | 7 | 7 |
| Episode 3 | 14 | 9 | 9 |
| **Total** | **36** | **24** | **24** |

### Step 3: Batch Export

```
1. Select all clips
2. Apply export settings
3. Queue for export
4. Download to local folder
5. Upload to scheduling tool
```

## Optimization Tips

| Tip | Implementation | Result |
|-----|----------------|--------|
| Batch upload | Process 5+ episodes at once | 3x faster workflow |
| Template reuse | Save caption styles | Consistent branding |
| AI suggestions | Trust AI for initial cuts | 60% less editing |
| Preview first | Review before export | Fewer re-exports |
| Organize clips | Use folders by topic | Easier management |

## Quality Checklist

Before exporting, verify:

- [ ] Captions are accurate (no typos)
- [ ] Audio levels are balanced
- [ ] Logo is visible but not intrusive
- [ ] Clip makes sense without context
- [ ] CTA is clear
- [ ] Duration is optimal (15-60s)
- [ ] Export settings match platform
