# Podcast Repurposing Strategy

## Overview

This guide outlines the systematic approach to converting long-form podcast/stream content into engaging short-form clips for YouTube Shorts and Instagram Reels using AI-powered tools.

---

## Content Pipeline

### Source to Distribution Flow

```
┌─────────────────────────────────────────────────────────────┐
│                    CONTENT PIPELINE                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  [1. SOURCE]        [2. ANALYZE]       [3. SELECT]          │
│  Podcast/Stream  →  Pictory AI    →   Highlight Clips       │
│  (1-3 hours)        Auto-transcribe    (8-12 per hour)       │

│                     Score engagement                         │
│                                                              │

│  Add effects        Add music          TikTok               │
│                     Add CTA            Twitter/X             │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## Phase 1: Source Content Preparation

### Ideal Source Content

| Content Type | Duration | Clip Potential | Quality Notes |
|--------------|----------|----------------|---------------|
| Full podcast episode | 60-90 min | 8-12 clips | Best for depth |
| Live stream highlight | 30-60 min | 5-8 clips | Raw, authentic |
| Interview segment | 20-45 min | 4-6 clips | Great quotes |
| Tutorial/Guide | 15-30 min | 3-5 clips | Educational value |
| Reaction video | 10-20 min | 2-4 clips | Emotional peaks |

### Audio Quality Requirements

| Requirement | Minimum | Optimal |
|-------------|---------|---------|
| Sample rate | 44.1kHz | 48kHz |
| Bit depth | 16-bit | 24-bit |
| Format | MP3 128kbps | WAV/FLAC |
| Noise level | < -60dB | < -70dB |
| Peak level | < -3dB | < -6dB |

## Phase 2: AI Analysis & Selection

### Pictory AI Scoring System

| Score | Meaning | Action |
|-------|---------|--------|
| 90-100 | Viral potential | Priority clip |
| 80-89 | High engagement | Must include |
| 70-79 | Good content | Include if room |
| 60-69 | Average | Skip unless unique |
| <60 | Low value | Skip |

### Clip Selection Criteria

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Emotional impact | 30% | Excitement, surprise, humor |
| Standalone value | 25% | Makes sense without context |
| Audio clarity | 20% | Clear speech, no background noise |
| Visual interest | 15% | Engaging gameplay/visuals |
| Brand alignment | 10% | Matches game's tone/message |

### Topic Detection Categories

| Category | Keywords | Clip Types |
|----------|----------|------------|
| Gameplay | "look at this", "watch this", "oh my god" | Highlights, reactions |
| Tips | "pro tip", "here's how", "secret" | Tutorials, guides |
| Humor | "lol", "that's hilarious", "no way" | Funny moments |
| Drama | "can't believe", "insane", "wild" | Epic moments |
| Community | "shoutout", "thanks for", "love you" | Community building |

## Phase 3: Clip Editing Workflow

### CapCut Editing Checklist

```
□ Import clip from Pictory export
□ Trim to optimal length (15-45 seconds)
□ Add hook in first 2 seconds
□ Generate auto-captions
□ Apply brand kit:
  □ Logo overlay (top-right, 15% opacity)
  □ Brand colors for captions
  □ Intro/outro (optional)
□ Add background music (30% volume)
□ Layer original audio (100% volume)
□ Add sound effects:
  □ Whoosh for transitions
  □ Impact for highlights
  □ Ding for reveals
□ Add CTA in final 3 seconds
□ Export: 1080x1920, 30fps, MP4
```

### Caption Styling Guide

| Element | Font | Size | Color | Animation |
|---------|------|------|-------|-----------|
| Main text | Montserrat Bold | 48px | White | Pop-in |
| Emphasis | Same | 56px | Yellow | Pulse |
| CTA | Same | 44px | Green | Slide-up |
| Outline | Same | +2px | Black | Static |

### Timing Optimization

| Segment | Duration | Purpose |
|---------|----------|---------|
| Hook | 0-2s | Stop the scroll |
| Buildup | 2-5s | Create anticipation |
| Peak | 5-15s | Deliver value/payoff |
| CTA | 15-20s | Drive action |
| **Total** | **15-20s** | **Optimal for Shorts** |

## Quality Assurance

### Pre-Export Checklist

- [ ] Hook is compelling (first 2 seconds)
- [ ] Captions are accurate (no typos)
- [ ] Audio levels are balanced
- [ ] Clip makes sense without context
- [ ] CTA is clear and actionable
- [ ] Brand elements are present
- [ ] Duration is optimal (15-60s)
- [ ] Export settings match platform

### Post-Export Review

- [ ] Video plays correctly
- [ ] Audio syncs properly
- [ ] Captions display correctly
- [ ] Logo is visible
- [ ] File size is reasonable (<50MB)
- [ ] Filename follows convention: `[Platform]_[Topic]_[Date].mp4`
