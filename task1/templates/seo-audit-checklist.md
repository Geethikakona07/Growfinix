# SEO Audit Checklist

## Luxury Property Website — On-Page SEO Audit

---

## Title Tags
- [ ] Title tag is 50-60 characters
- [ ] Primary keyword is at the beginning
- [ ] Brand name is included (if applicable)
- [ ] Title is unique for each page
- [ ] Title is compelling and click-worthy
- [ ] No keyword stuffing

## Meta Descriptions
- [ ] Meta description is 150-160 characters
- [ ] Primary keyword is included naturally
- [ ] CTA is included
- [ ] Description is unique for each page
- [ ] Description matches search intent
- [ ] No duplicate meta descriptions

## Header Tags (H1-H6)
- [ ] Only ONE H1 tag per page
- [ ] H1 contains primary keyword
- [ ] Proper heading hierarchy (H1 > H2 > H3)
- [ ] H2 tags include secondary keywords
- [ ] Headers are descriptive and useful

## Image Optimization
- [ ] Every image has alt text
- [ ] Alt text is descriptive and under 125 characters
- [ ] Images are compressed (WebP format)
- [ ] Lazy loading is implemented
- [ ] Image file names are descriptive

## URL Structure
- [ ] URLs are short and descriptive
- [ ] Primary keyword is included
- [ ] URLs use hyphens (not underscores)
- [ ] URLs are lowercase
- [ ] No dynamic parameters

## Internal Linking
- [ ] No orphan pages (pages with no internal links)
- [ ] Anchor text is descriptive (not "click here")
- [ ] Important pages are within 3 clicks of homepage
- [ ] Breadcrumb navigation is present
- [ ] No broken internal links

## External Linking
- [ ] Links to authoritative sources
- [ ] External links open in new tab
- [ ] No broken outbound links
- [ ] Nofollow used where appropriate

## Canonical Tags
- [ ] All pages have self-referencing canonicals
- [ ] No incorrect canonical pointers
- [ ] HTTP/HTTPS canonicals are consistent

## Schema Markup
- [ ] Organization schema present
- [ ] LocalBusiness schema present
- [ ] FAQPage schema on relevant pages
- [ ] Review/AggregateRating schema present
- [ ] BreadcrumbList schema present
- [ ] RealEstateListing schema on property pages

## Technical
- [ ] XML sitemap exists and is submitted to GSC
- [ ] robots.txt includes Sitemap directive
- [ ] HTTPS is enforced (no mixed content)
- [ ] No redirect chains or loops
- [ ] Core Web Vitals are "Good"
- [ ] Mobile-friendly design
- [ ] No duplicate content issues
