## Story Types

| Type | Description | Best For |
|------|-------------|----------|
| **Poll** | Yes/No or This/That | Engagement, decisions |
| **Quiz** | Multiple choice questions | Education, fun |
| **Question Box** | Open-ended Q&A | Community, feedback |
| **Slider** | Emoji rating scale | Reactions, opinions |
| **Countdown** | Event/product launch | Hype, urgency |
| **Link** | Drive to website/product | Conversions |
| **Photo/Video** | Behind the scenes | Brand personality |

## Story Engagement Tactics

| Tactic | How to Use |
|--------|------------|
| **Polls** | Use for decisions, preferences, "this or that" |
| **Questions** | Ask open-ended questions to get DMs |
| **Quizzes** | Test knowledge, make it fun |
| **Sliders** | Let people rate/react to content |
| **Countdowns** | Build hype for launches and events |
| **Links** | Drive traffic to website/product pages |
| **Mentions** | Tag customers to encourage resharing |

---

## Story Best Practices

| Tip | Detail |
|-----|--------|
| **Post 3-5 stories/day** | Stay top of mind without overwhelming |
| **Use interactive stickers** | Boost engagement and algorithm ranking |
| **Keep text minimal** | 1-2 lines max per story |
| **Use brand colors** | Consistent visual identity |
| **Add music** | Makes stories more engaging |
| **Save to Highlights** | Organize by category |
