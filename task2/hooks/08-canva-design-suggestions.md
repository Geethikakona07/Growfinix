## Canva AI Design Assistant Tips

| Feature | How to Use |
|---------|------------|
| **Magic Design** | Upload photo → AI generates template options |
| **Text to Image** | Describe your vision → AI creates custom images |
| **Magic Eraser** | Remove unwanted elements from photos |
| **Magic Expand** | Extend image borders without distortion |
| **Brand Kit** | Save colors, fonts, logos for consistency |
| **Bulk Create** | Upload CSV → Generate multiple designs at once |

## Content-Specific Design Suggestions

### Product Showcase Posts
- Use Canva's **Product Mockup** templates
- Add **minimal text** overlay
- Use **consistent background** (white/cream)
- Add **gold accent** for luxury feel

### Educational Carousels
- Use **numbered slides** for easy following
- Keep **font sizes large** (readable on mobile)
- Use **icons** from Canva's library
- End with **branded CTA slide**

### Behind-the-Scenes Stories
- Use **casual, candid** style
- Add **handwritten-style fonts**
- Include **interactive stickers**
- Keep **brand colors** consistent

---

## Design Workflow

```
1. Open Canva → Choose template size
2. Apply Brand Kit (colors, fonts, logo)
3. Upload product photos
4. Use AI Design Assistant for suggestions
5. Customize layout and text
6. Export as PNG (posts) or MP4 (Reels)
7. Schedule in content planner
```
