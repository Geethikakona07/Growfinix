# 01 — Schema Markup Guide

## Medical Clinic — Complete Schema Implementation

---

## Schema Types Required

| Schema Type | Purpose | Pages | Priority |
|-------------|---------|-------|----------|
| MedicalClinic | Identify clinic | Homepage, Contact | Critical |
| Physician | Identify doctors | Doctor pages | Critical |
| MedicalCondition | Define conditions | Service pages | High |
| MedicalProcedure | Define procedures | Service pages | High |
| FAQPage | Answer questions | All pages | Critical |
| Review | Patient testimonials | Homepage, Reviews | High |
| Article | Blog content | Blog posts | High |
| BreadcrumbList | Navigation | All pages | Medium |
| LocalBusiness | Local SEO | Homepage | Critical |

---

## Schema Implementation Order

1. **Week 1:** MedicalClinic + LocalBusiness (Homepage)
2. **Week 1:** Physician (Doctor pages)
3. **Week 2:** FAQPage (All service pages)
4. **Week 2:** Review (Homepage, Reviews page)
5. **Week 3:** Article (Blog posts)
6. **Week 3:** BreadcrumbList (All pages)
7. **Week 4:** MedicalCondition + MedicalProcedure (Service pages)

---

## Schema Validation Tools

| Tool | URL | Purpose |
|------|-----|---------|
| Google Rich Results Test | search.google.com/test/rich-results | Validate schemas |
| Schema Markup Validator | validator.schema.org | Check syntax |
| Google Search Console | search.google.com/search-console | Monitor performance |

---

## Schema Testing Checklist

- [ ] All schemas validate without errors
- [ ] Rich results appear in Google Search Console
- [ ] No duplicate schemas on same page
- [ ] All required properties are included
- [ ] Optional properties added where relevant
- [ ] Schema matches visible page content
- [ ] Test across multiple pages
